# 私人文献库 / Private Library

一个**本地私有**的论文阅读与思考管理工具。把读过的论文按「项目 → 无限嵌套文件夹」组织起来，记录每篇论文的元信息（期刊 / 作者 / 中英文标题 / 日期 / DOI），并随手记下它带给你的**思考**——文字或截图都可以。

界面完全复用「推送公众号论文」项目的视觉框架（墨色 + 纸面 + 氧化绿 + 铜橙配色、抽屉、卡片、动画），风格一致。

## 核心定位

> PDF 原文不存进库里。库里存的是**元信息 + 一条指向你电脑里真实 PDF 的路径**，随时一键跳回原文件。真正沉淀下来的是「这篇文章对我有什么用」——那才是写论文做引用时最难的部分。

## 功能

| 功能 | 说明 |
|------|------|
| 账号系统 | 注册 / 登录，本地 token，数据隔离 |
| 项目管理 | 一个课题一个项目，可写备注 |
| 无限嵌套文件夹 | 文件夹里可以继续建文件夹，也可放论文 |
| 论文录入（3 种） | 拖入 PDF 自动解析、点选本地 PDF、手动填写 |
| 元信息展示 | 英文标题 + 中文标题（自动翻译）+ 期刊 + 作者 + 发表日期 + DOI |
| 期刊识别 | DOI 前缀映射表优先（j.watres→Water Research 等），覆盖常读期刊 |
| 中文标题自动翻译 | 复用 translator（Google + MyMemory 双引擎），提取后自动填中文标题 |
| 本地路径自动定位 | 拖入 PDF 后按文件名在论文目录搜索同名文件，自动填路径（可改） |
| 思考标注（图文混排） | 富文本编辑区：文字 + 多张截图 + 图间插话 + 换行缩进，点「保存思考」才提交为一条 |
| 截图粘贴 | 编辑区 `Ctrl+V` 粘贴到光标处，存到 `picture asset/` |
| 本地跳转 | 「打开 PDF」直接打开原文件，「打开所在文件夹」定位文件 |
| 结构化回收站（7 天保留） | 删除的项目、文件夹、论文按“项目 → 文件夹 → 论文”归类；可多选恢复或永久删除，超过 7 天自动清理 |
| 双视图切换 | 论文视图（按项目 / 论文组织，复习单篇）↔ 观点视图（按观点组织，写文章时索引引用），侧栏顶部切换 |
| 观点库（全局一套） | 观点 → 文件夹 → 文件 三层树，不隶属于任何项目，跨项目跨时间复用 |
| 条目单一归属 | 一条思考最多挂在一个观点「文件」下；未归属的叫「游民」，仍在论文页可见 |
| 来源文献强制绑定 | 观点视图里新增条目必须先选库内论文（可搜索），条条可溯源、可跳转 |
| 导入查重 | 保存前按 DOI → 标题 → 归一化标题前段三级比对，命中则弹「引用已有 / 打开已有 / 仍然导入」 |
| 重复论文清理 | 侧栏「重复清理」扫描全库重复记录，每组选一条保留，其余条目全部归拢后并入回收站（7 天可恢复） |
| 论文视图按观点分组 | 打开单篇论文，思考按所属观点文件分组排列，顶部「被 N 个观点引用」可一键跳过去，未归属的单列「游民」区 |
| 逐条归属操作 | 每条思考都有「归属」菜单：加入某个观点 / 移到别的观点 / 清除归属变游民，两种视图都能用 |
| 导入已有论文 | 项目内「导入已有论文」把库里已有的论文引用到当前文件夹，同一条记录出现在多处，不产生重复 |
| 撤销删除（后退一步） | 删除思考后提示条上可一键撤销，8 秒内有效 |

## 快速开始

### 首次安装依赖

```powershell
cd A:\workbuddy项目\私人文献库
python -m venv .venv
.venv\Scripts\pip install pdfplumber pypdf
```

### 启动

双击 `web\start_web.cmd`，或：

```powershell
cd web
powershell -ExecutionPolicy Bypass -File start_web.ps1
```

浏览器自动打开 `http://127.0.0.1:8040`，首次使用先「注册一个」账号。

## 使用流程

1. **注册登录** → 创建自己的账号
2. **新建项目** → 右上角「新建项目」，如「反渗透膜隔网 CFD」
3. **建文件夹** → 项目内左侧「文件夹树」可无限建子文件夹
4. **导入论文** → 右上角「导入论文」：
   - 拖入本地 PDF，自动提取标题 / 作者 / 期刊 / 日期 / DOI，核对后保存
   - 也可手动填写，并填「本地 PDF 路径」以便一键跳转
5. **记思考** → 点开论文，在「我的思考」区写文字，或直接 `Ctrl+V` 粘贴截图
6. **写论文时** → 切到「观点视图」，建观点（如「压力操作」「隔网几何」），在其下建文件，新增条目时先选来源论文再写内容
7. **回到单篇复习** → 切回「论文视图」，论文页能看到每条思考归属于哪个观点，也能看到这篇被哪几个观点引用过
8. **定期清理** → 侧栏「重复清理」合并重复导入的论文

## 双视图：论文视图 ↔ 观点视图

侧栏顶部两个按钮切换，同一份数据、两种组织方式：

| | 论文视图 | 观点视图 |
|---|---|---|
| 组织轴 | 项目 → 文件夹 → 论文 | 观点 → 文件夹 → 文件 |
| 典型场景 | 复习单篇、补元信息 | 写文章时按观点索引引用 |
| 条目顺序 | 按创建时间 | 按观点文件分组 |
| 归属 | 论文天然属于项目 | 条目最多归属一个观点文件 |

设计要点：

- **观点库是全局的**，不挂在某个项目下——同一个观点（如「压力操作」）会跨项目、跨时间复用，被引论文列表会从 10 篇长到 15 篇。
- **单一归属**：一条思考只挂在一个观点文件下，不做多对多。如果一张截图同时讲了压力和流场，就在两个观点文件里各贴一次、各自取舍——那是截图粒度的问题，不是数据模型的问题。
- **来源文献强制绑定**：在观点视图里新增条目，第一步必须先选库内论文；不在库里的先「+ 新增论文」。这样每条思考都能一键跳回来源。
- 历史上的旧条目不会丢，自动变成「游民」（未归属任何观点），在论文视图里照常可见，之后可再归到某个观点下。
- **论文视图是反查轴**：打开一篇论文，思考按所属观点文件分组排列，顺序跟观点文件创建时间一致；顶部一条「被 N 个观点引用」胶囊条，点任意胶囊直接跳到观点视图打开那个文件；未归属的思考收在末尾的「游民」区。
- **归属随时可调**：每条思考（论文抽屉、View 页、观点文件里都有）带「归属」菜单——加入某个观点 / 移到别的观点 / 清除归属变游民。清除只解除归属，**思考本身不会被删**。

## 重复论文与导入查重

同一篇论文被重复导入会让条目散在多份记录上。两个机制一起防止这件事：

1. **导入时查重**：保存论文前先用 DOI 精确比对，没 DOI 再比标题；两者都没命中时，再比「归一化标题前 25 个字符」（去掉标点空格并小写，能扛住 PDF 解析出来的截断 / 连字符 / 全半角差异）。
   命中后弹窗三选一：
   - **引用已有论文到当前文件夹** —— 不新建记录，同一条记录出现在两个文件夹里（`paper_placement`）
   - **打开已有论文** —— 先去看看是不是同一篇
   - **仍然导入为新论文** —— 确实是不同的两篇时用它，之后还能在「重复清理」里合并

2. **重复清理**（侧栏「重复清理」）：按 DOI（无 DOI 时按归一化标题）分组扫描全库，每组默认推荐保留「条目最多、最早导入」的那条，其余的思考全部归拢到保留记录上，被合并的记录进回收站，**7 天内可恢复**。侧栏按钮上的角标显示当前有几组重复。

> 合并只搬动条目和放置位置，不会删思考；原始 PDF 与截图资产不动。

## 局域网 / Zerotier 访问

后端默认监听 `0.0.0.0`，同一 Zerotier 网络内的其它设备可通过 `http://10.44.55.169:8040` 访问。

首次使用需放行 Windows 防火墙（需管理员权限，一次即可）：

1. 双击 `web\run_zerotier_admin.bat`
2. 弹出的 UAC 窗口点「是」
3. 脚本自动创建「Private Library ZeroTier 8040」入站规则，仅允许 `10.44.55.0/24` 网段访问

> 也可手动：右键 PowerShell「以管理员身份运行」→ `powershell -ExecutionPolicy Bypass -File web\enable_zerotier_access.ps1`

## PDF 元信息提取

后端用 `pdfplumber` 解析 PDF 首页，启发式提取：

| 字段 | 提取方式 | 可靠性 |
|------|----------|--------|
| 标题 | 首页最大字号文本块（自动剔除页眉期刊名） | 高 |
| DOI | 正则 `10.xxxx/…` | 高 |
| 发表日期 | `Received/Accepted/Available online/© 年份`（兼容两种日期格式） | 中 |
| 期刊名 | **DOI 前缀映射表优先**（j.watres→Water Research 等），兜底页眉卷号行/版权行 | 高 |
| 作者 | 标题下方姓名行 | 中 |
| 中文标题 | 自动翻译（Google + MyMemory 双引擎 + 缓存） | 高（联网时） |

> 主流文字版 PDF 提取稳定；**扫描版（无文字层）暂不支持**，需要 OCR（后续可加）。所有字段保存前都可手动修改。

## 数据与隐私

- 全部数据存本地 `data/library.db`（SQLite）与 `picture asset/` 目录
- 无任何联网上传，账号密码本地 PBKDF2 哈希存储
- 端口 `8040`，监听 `0.0.0.0`（本机 + Zerotier 局域网均可访问，防火墙规则控制来源）

## 技术要点

- 后端：`BaseHTTPRequestHandler` + `ThreadingHTTPServer`（纯标准库），沿用观察台架构
- 数据库：`sqlite3` 标准库，外键级联删除（删文件夹自动删论文、删论文自动删标注与图片记录）
- 无限嵌套：`folder.parent_id` 自引用，前端递归渲染文件夹树
- 截图：前端 `paste` 事件捕获剪贴板图片 → base64 → 后端存 `picture asset/<项目>/<论文>/`
- 本地跳转：后端 `os.startfile` 打开 PDF / `explorer /select` 定位文件
- 观点树：`topic_node` 自引用树（`topic` / `folder` / `file` 三层），`note.topic_file_id` 单值可空外键，删观点时把其下条目的归属置空（变回游民）而不是删条目
- 跨项目共享：`paper_placement(paper_id, project_id, folder_id, is_primary)`，同一条论文记录可出现在多个项目 / 文件夹，列表用 `OR EXISTS` 过滤避免重复行
- WAL 落盘：启动时 `PRAGMA wal_checkpoint(TRUNCATE)` 合并上次残留的 WAL，之后后台线程每 60 秒 `PASSIVE + TRUNCATE` 合并一次。避免「已提交的数据只活在 WAL 里」，进程被强杀也不丢

## 删除与回收（2026-08 更新）

- 项目、文件夹、论文支持勾选后批量删除；Ctrl / Cmd 可增减选择，Shift 可选择连续范围
- 删除项会进入结构化回收站，按原来的项目、文件夹路径和论文分类展示
- 每条回收记录包含删除时间和剩余保留天数，默认保留 **7 天**
- 回收站支持多选恢复、多选永久删除；永久删除会清理对应的论文记录、笔记和截图资产，无法恢复
- 超过 7 天的回收项会在系统下一次运行或打开回收站时自动清理
- 旧版 `data/deleted.json` 会自动迁移为回收记录，用于兼容已有已删除内容；新的记录保存在本地 SQLite 数据库中并按账号隔离
